# Card Guessing Game

## Introduction

The **Card Guessing Game** is an interactive memory game where players match pairs of cards. The game tracks the player's time and compares it to the high score, providing a fun way to improve memory skills.

---

## How to Play

1. The game starts with shuffled cards face down.
2. Click on two cards to reveal them.
3. If the two cards match, they stay face-up. If not, they flip back over.
4. Continue flipping cards until all pairs are matched.
5. Your time is recorded, and you can check if you achieved a high score.

---

## Features

- **Timer**: The game records how long it takes to match all pairs.
- **High Score System**: Players can save their fastest time and check the leaderboard.
- **Responsive Design**: The game is designed to work on all screen sizes.
- **Congratulations Popup**: A popup appears when all pairs are successfully matched.

---

## Technologies Used

- **HTML5**: For creating the structure of the game.
- **CSS3**: For styling the game elements.
- **JavaScript (ES6)**: For game logic and interactivity.
- **Node.js**: Backend framework to handle score saving.
- **Express**: Web server framework for Node.js.
- **EJS**: Templating engine for rendering the game page.
